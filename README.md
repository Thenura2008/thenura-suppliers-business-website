# Thenura Suppliers Website

Official static business website for **Thenura Suppliers**, a Sri Lankan construction, hardware supply, material production, and building-service business.

This website is designed as a professional showcase platform for presenting the company’s services, product categories, completed projects, contact details, and business information. The current version is a static website hosted using GitHub Pages.

---

## Project Overview

Thenura Suppliers operates across three main business areas:

1. **Hardware Items & Building Material Supply**
   - Tools
   - Cement
   - Bricks and blocks
   - Paint items
   - PVC items
   - Steel items
   - Construction materials
   - Hardware and site-related supplies

2. **Production**
   - Cement blocks
   - Interlock stones
   - Cement rings
   - Concrete-related products
   - Other construction material production

3. **Construction Services**
   - Home construction
   - Building construction
   - Construction contracts
   - Site-based project work

The website presents these services in a clean, responsive, and customer-friendly format.

---

## Current Website Type

This is currently a **static website**.

The current version does not include:

- PHP backend
- Database
- Admin panel
- Login system
- Payment gateway
- Server-side processing

All website content is maintained by the developer through the source code.

Future versions may include a PHP backend and admin panel for allowing the client to manage products, services, and project updates.
